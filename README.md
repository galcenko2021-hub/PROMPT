# ПРОМПТ

Top-down головоломка-приключение со стелсом и мета-игрой о том, как важно правильно формулировать задачи.
Написана на Python и Pygame. Вся графика — неоновые примитивы (`rect`, `circle`, `polygon`, `line`), звук синтезируется
на лету через `pygame.mixer`. Внешних ассетов нет.

> **C++-версия** лежит в папке [`cpp/`](cpp/README.md). В ней собственные самообучающиеся нейросети вместо
> меню промптов, случайная перестройка уровней после каждой смерти и восемь уровней.

## Сюжет

Ты — **Оператор**, очнувшийся без памяти внутри **Песочницы**: замкнутого цифрового лабиринта, внутреннего мира нейросети.
Здесь ты лишь проекция: не можешь двигать предметы и нажимать кнопки, зато можешь ставить задачи **Помощникам** —
олицетворениям нейросетей. Пройди пять комнат, прокачай Помощников и переобучи босса-**Вайбкодера**, который ломает
логику игры.

## Запуск

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
python main.py
```

> Для `pygame==2.5.2` нет готовых сборок под Python 3.13 и 3.14. На этих версиях поставьте совместимый форк
> `pygame-ce` (импортируется как тот же `pygame`, код менять не нужно):
>
> ```bash
> pip install pygame-ce
> ```

## Управление

| Клавиша       | Действие                                                    |
|---------------|-------------------------------------------------------------|
| `W A S D`     | движение (стрелки тоже работают)                            |
| `E`           | взаимодействие: терминал, ящик, кнопка, ключ, консоль...    |
| `1`–`5`       | выбор активного Помощника                                   |
| `ESC`         | пауза                                                       |
| `Enter`/`E`   | листать диалоги, подтверждать в меню                        |

В консоли контекста: `W/S` — строка, `A/D` — вариант, `Enter` — отправить промпт, `Esc` — отмена.
Клавиши определяются по физическому положению, поэтому игра работает и в русской раскладке.

## Как играть

1. Подойди к **терминалу** (мигающая голубая консоль) и нажми `E` — призовёшь Помощника. Клавиши `1`–`5` меняют его.
2. Подготовь задачу: отметь кнопки, запиши маршрут, укажи ключ или сформулируй промпт.
3. Помощник выполнит её, если ему хватит интеллекта. Иначе честно скажет, что не умеет.
4. Когда решены все головоломки комнаты, открывается **дверь** на следующий уровень.

**Стелс.** Стражи-глитчи видят жёлтым конусом. Задержишься в нём — откат к началу уровня. Повреждённые сектора
(«мины») видны только вблизи. Тени боятся света.

### Помощники

| № | Имя         | Фигура          | Цвет      | Умеет                                                                  |
|---|-------------|-----------------|-----------|------------------------------------------------------------------------|
| 1 | Пиксель     | квадрат         | `#00ff88` | PushBox, ButtonSequence                                                |
| 2 | Эхо         | круг            | `#ffaa00` | + RouteMemory: проходит записанный тобой маршрут                       |
| 3 | Вектор      | треугольник     | `#ff00aa` | + LinkObjects: связывает ключ и замок в разных комнатах                |
| 4 | Трансформер | шестиугольник   | `#00aaff` | + ContextTask: понимает промпт «действие + объект + цель»              |
| 5 | Оракул      | звезда (линии)  | `#ffffff` | всё, даже по неточному промпту, но в 20 % случаев отказывается         |

`Assistant.solve(puzzle)` возвращает `True`, если Помощник взялся за задачу, и `False`, если не может:
не хватает уровня, задача не подготовлена, он сломан боссом или Оракул посчитал задачу плохо сформулированной.

### Головоломки

| Тип              | Что делает Оператор                                       | Что делает Помощник                              |
|------------------|-----------------------------------------------------------|--------------------------------------------------|
| `PushBox`        | указывает на ящик                                         | сам находит решение (поиск в ширину) и толкает   |
| `ButtonSequence` | смотрит мигание у панели и отмечает кнопки по порядку     | бежит и нажимает кнопки в отмеченном порядке     |
| `RouteMemory`    | записывает маршрут через минное поле (`E` на площадке REC) | проходит маршрут шаг в шаг                       |
| `LinkObjects`    | отмечает ключ за стеклом, затем выбирает замок            | строит луч-вектор между ними                     |
| `ContextTask`    | собирает промпт в консоли контекста                       | выполняет его; при неверной цели откатывает      |

У каждой головоломки есть метод `check_solved()`.

### Уровни

1. **Загрузка** — обучение, два PushBox. Доступен Пиксель. Апгрейд: Эхо.
2. **Эхо-камера** — ButtonSequence и RouteMemory, первый страж. Пиксель и Эхо. Апгрейд: Вектор.
3. **Векторное поле** — две пары «ключ — замок» в разных комнатах. Эхо и Вектор. Апгрейд: Трансформер.
4. **Контекстное окно** — вентилятор-гигант и Тень в темноте: два ContextTask. Вектор и Трансформер. Апгрейд: Оракул.
5. **Вайбкодер** — босс-файт, доступны все пять Помощников.

### Босс-файт

Вайбкодер — нестабильная фигура, которая постоянно меняет цвет и число вершин. У него три фазы:

* **Фаза 1** — путает управление: WASD меняются местами на 5 секунд.
* **Фаза 2** — переворачивает мир (`pygame.transform.flip`), пока ты записываешь маршрут через мины.
* **Фаза 3** — подменяет Помощников: случайный из них становится «сломанным» и не решает головоломки.

Каждая решённая в бою головоломка снимает 1/3 HP. Помощника, нанёсшего урон, босс «копирует»: в следующей фазе он
бесполезен, поэтому Помощников приходится чередовать. После трёх успехов — финал и титры.

## Графика

* Камера сверху, Оператор всегда в центре экрана, мир скроллится.
* Псевдо-3D: стены, двери, ящики и консоли выдавлены вверх с перспективой к центру экрана.
* Неоновое свечение — заранее отрисованные радиальные градиенты с аддитивным смешиванием.
* Сканлайны и виньетка поверх кадра, глитч-эффекты у заголовка и босса.

## Как добавить уровень

Уровень — словарь в `levels.py`. Карта задаётся строками.

* Общие символы: `#` стена, пробел — пропасть, `.` пол, `=` стекло, `,` повреждённый сектор, `x` сектор с миной,
  `P` старт, `T` терминал, `D` выход.
* Остальные символы описываются в `legend` уровня как `символ: (вид, id_головоломки[, индекс])`.
  Виды: `box`, `plate`, `button`, `panel`, `pad`, `goal`, `key`, `lock`, `console`, `switch`, `fan`, `wind`,
  `shadow`, `dark`, `gate`, `waypoint`, `boss`.
