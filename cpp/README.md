# ПРОМПТ — C++ версия с собственными нейросетями

Та же игра, что и на Python, но переписанная на C++. Главное отличие: Помощники — **настоящие нейросети**,
написанные с нуля. Внешних API нет. Ты пишешь задачу своими словами, нейросеть рассуждает над ней (ход
рассуждений виден на экране), выполняет её и **учится на твоей игре**.

## Что нового по сравнению с Python-версией

- **Свои модели вместо меню.** Промпт пишется свободным текстом по-русски. Каждый Помощник — своя нейросеть:

  | Помощник    | Модель                                              | Параметров |
  |-------------|-----------------------------------------------------|-----------:|
  | Пиксель     | линейная модель на хешированных признаках слов      |     ~55 000 |
  | Эхо         | перцептрон, 24 нейрона ReLU                         |     ~50 000 |
  | Вектор      | перцептрон, 48 нейронов ReLU                        |    ~100 000 |
  | Трансформер | 1 блок трансформера: self-attention + FFN, d = 32   |     ~75 000 |
  | Оракул      | 2 блока трансформера, d = 48                        |    ~138 000 |

  Все слои, обратное распространение ошибки и оптимизатор Adam написаны вручную (`brain/nn.py`).
  numpy используется только как хранилище массивов.
- **Рассуждения на экране.** Справа панель «Мысли»: какие слова повлияли на решение (метод окклюзии), куда
  смотрело внимание трансформера, гипотезы с вероятностями, проверка «есть ли такой объект в комнате» и итоговое
  решение с уверенностью. Не уверен — Помощник переспрашивает.
- **Самообучение.**
  - При первом запуске модели предобучаются на синтетическом корпусе перефразировок: синонимы, порядок слов,
    опечатки. Это занимает около 30 секунд и идёт в фоне. Пиксель готов уже через секунду.
  - Каждая успешно выполненная задача закрепляет формулировку.
  - Если Помощник понял не так, нажми `Tab` и укажи, что ты имел в виду. Модель дообучится на этом примере и
    запомнит его навсегда.
  - После уровня модели «спят»: повторяют выученное вперемешку с корпусом.
  - Веса и выученные фразы хранятся в `models/` и переживают перезапуск. Сбросить модель можно в меню
    «Нейросети Помощников».
- **Рандом после каждой смерти.** Песочница перестраивается: ящики и плиты, кнопки и их порядок, мины и
  безопасная тропа, пары ключ — замок, места выключателей и маршруты стражей. Каждая раскладка проверяется на
  решаемость: решатель сокобана и поиск безопасного пути.
- **Восемь уровней вместо пяти.** Добавлены «Шумный датасет», «Галлюцинации» и «Обучающая выборка».
- **Босс** в третьей фазе по-настоящему портит веса нейросети случайного Помощника. Он начинает понимать
  промпты неправильно, и это видно в его рассуждениях.

## Запуск

Нужны Windows 10/11, Visual Studio 2022+ с компонентом «Разработка классических приложений на C++»,
а для нейросетей — Python 3.10+ с numpy.

```bat
cd cpp
build.bat
bin\prompt.exe
```

- Игра сама запускает `brain\server.py` скрытым процессом. Если Python не находится по команде `python`
  или `py -3`, укажи путь к нему в переменной окружения `PROMPT_PYTHON`.
- Если Python недоступен или процесс упал, игра не вылетает. Она трижды пытается перезапустить нейросети,
  а пока Помощники понимают только ключевые слова. Причина пишется в `models\brain.log`.
- Проверка нейросетей без игры: `python brain\test_brain.py`.

### Режимы для проверки

- `bin\prompt.exe --selftest` — автоматически проходит все 8 уровней, проверяет 40 случайных перестановок на
  каждом и проходит уровень ещё раз после перестановки. Результат пишется в `bin\selftest.log`.
- `bin\prompt.exe --shots <папка>` — сценарий с настоящими промптами к нейросетям. Сохраняет кадры в PNG.

## Управление

| Клавиша       | Действие                                                            |
|---------------|---------------------------------------------------------------------|
| `W A S D`     | движение (работает и в русской раскладке, стрелки тоже)             |
| `E`           | взаимодействие: у ящика, замка, консоли — открыть строку промпта    |
| `T` / `Enter` | написать промпт активному Помощнику                                  |
| `Tab`         | поправить последнюю мысль Помощника (он дообучится)                  |
| `1`–`5`       | выбрать Помощника                                                    |
| `Esc`         | пауза                                                                |

## Как это устроено

```
cpp/
├─ build.bat            сборка MSVC (сама находит Visual Studio)
├─ brain/               нейросети на Python (отдельный процесс)
│  ├─ nn.py             тензоры, autodiff, Adam — с нуля
│  ├─ language.py       токенизация, намерения, генератор корпуса
│  ├─ models.py         линейная модель, перцептроны, трансформеры; рассуждения и дообучение
│  ├─ server.py         протокол: JSON-строки через stdin/stdout
│  └─ test_brain.py     тесты моделей и протокола
├─ models/              веса и выученные фразы (создаётся при первом запуске)
└─ src/                 игра на C++20
   ├─ main.cpp          окно Win32, цикл, режимы --selftest и --shots
   ├─ game.*            состояния, промпт → нейросеть → решение → действие, обучение
   ├─ brain_client.*    запуск Python, асинхронные запросы, перезапуск, запасной режим
   ├─ intent.*          намерения и запасной разбор по ключевым словам
   ├─ json.*            разбор и сборка JSON
   ├─ render.*, gfx.*   Direct2D/DirectWrite: неон, свечение, псевдо-3D стены
   ├─ audio.*           синтез звуков через XAudio2
   ├─ player.*, assistant.*, puzzle.*, room.*, boss.*
   ├─ levels.*          восемь уровней
   └─ ui.*              HUD, промпт, панель мыслей, обучение, лаборатория, экраны
```

**Протокол.** Игра отправляет `{"id":7,"type":"think","level":4,"text":"…","objects":[5,1]}`.
Сервер отвечает намерением (действие, объект, цель), вероятностями гипотез, вкладом слов и вниманием.
Обучение — запрос `learn` с режимом `reinforce`, `correct` или `discourage`. Ответы приходят асинхронно:
игра не ждёт, а показывает «Помощник думает…».

**Честно об обучении.** Модели маленькие и учатся понимать формулировки. Знаний о мире у них нет: что именно
нужно сделать в комнате, решают правила игры. Поэтому «выключи вентилятор просто так» модель поймёт верно,
но Трансформер откажется выполнять это без нужной цели.
